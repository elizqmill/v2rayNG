# v2rayNG WL

Android-клиент на базе оригинального [v2rayNG](https://github.com/2dust/v2rayNG) (Xray / v2fly core) **без сторонних патчей**, с добавленными инструментами для жизни за «белыми списками» российских мобильных операторов.

> База синхронизирована с апстримом `2dust/v2rayNG`, поверх — только свои фичи. Никакого DeviceKit/happ и прочих модов.

---

## Возможности форка

### 🔍 Поиск стабильных профилей (проверка белых списков)

Меню ⋮ → **«Поиск стабильных профилей (проверка БС)»** в главном экране.

Зачем: у белых списков 2-го типа все IP пингуются, но скорость порезана до ~20 КБ/с. Обычная проверка задержки при этом бессмысленна — пинг есть у всех.

Как работает:
1. **Фаза пинга** — реальная задержка через ядро (как штатная «Проверить реальную задержку»), параллельно, с учётом настройки потоков. Профили с уже известным пингом не перепроверяются.
2. **Фаза скорости** — для каждого живого профиля (лучшие по пингу — первыми) поднимается временное ядро и качается тестовый файл с Cloudflare. До 8 ядер одновременно, чтобы не убить активный VPN.

Результат:
- рядом с пингом появляется **скорость**: 🟢 ≥ ~1 МБ/с · 🟠 200 КБ/с…1 МБ/с · 🔴 ниже
- пинг после замера скорости **не перезаписывается**
- профили без единого байта получают честный `0 KB/s`
- ⋮ → **«Сортировать по скорости»**

Настройки (Настройки → «Поиск по белым спискам»): таймаут TCP-пинга, размер тестового файла, таймаут скачивания, количество прогонов.

### 🔄 Пер-подписочные конвертеры

В настройках каждой подписки два независимых тумблера:

| Тумблер | Что делает при обновлении |
|---|---|
| **Base64 в текст** | Декодирует base64-ответ (целиком или построчно) в список ссылок |
| **Кастомные в ссылки** | Превращает JSON-профили в обычные `vless://` / `vmess://` / `ss://` / `trojan://` / `hysteria2://` / `tuic://` / `socks://` |

Конвертер понимает xray-обёртку (`outbounds/settings`), sing-box формат (`type/server/server_port`) и магазинные полные конфиги (в т.ч. Hysteria2 как `protocol:"hysteria"` + `hysteriaSettings`). Несконвертируемое не теряется — остаётся кастомным профилем.

Выключены по умолчанию: каждая подписка решает сама.

### ⚙️ Сборка

Каждый пуш в `master` автоматически собирает подписанные APK через GitHub Actions и публикует релиз (`v{версия}-wl-{дата}`): варианты `fdroid` и play-store × arm64 / armeabi-v7a / x86 / x86_64 / universal.
